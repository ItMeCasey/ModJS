## Found while testing

- On 26.3 the title screen never has bound item components (15,192 failed attempts in one run), so the first fix (skip and retry) only avoided the crash and drew no icon. The 26.x builds now fall back to the item's own texture file (`textures/item/NAME.png`, then `textures/block/NAME.png`) when no stack can be built. Emerald and diamond draw; the compass does not, because it has no single flat texture, and items without one draw nothing on the title screen. Inside a world the real item model is drawn as before.
