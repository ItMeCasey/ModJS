## Not run

- Client tours and headless self tests on the other eight builds (they compile and share the code that passed).
- The in-world recipe pages in the JEI, EMI and REI windows. The pages are added to the shared information event that all of them read; the client tour checked that event, not the viewer screens.
- Anvil, lightning and random tick in a real client (they were exercised through the adapters in the self test; the anvil hook relies on a landed falling anvil being discarded).
- The Forge and NeoForge 1.20.1 jars in a real install (only the SRG name count).

## Found while testing

- A drop spawned by a recipe is not always visible to an entity query in the same tick (26.x), so the self test reads the engine's own spawn record (`WorldCraftAdapters.recentSpawns()`), and the client tour does too.
- Dropped items given a random push left a one-block pool before the scan ran; the tour spawns them without motion.
