## Frames (docs/frames)

`worldoverlay-<module>-world.png`: floating title with background, progress bar, item icon and a texture on the top face over the smelter (made of different textures per face, front turned to the player), and the same four element kinds over a plain stone block (texture on its north face). On Forge 26.3 only the smelter has an overlay: that build draws through block entity renderers (see docs/PORTING.md).
`worldoverlay-<module>-screen.png`: the smelter's own screen: slots at the script's positions, raw iron and iron ingots, the progress bar, the Pause button and the player inventory.

## Second pass (same day)

- Client tours on NeoForge 1.20.1, NeoForge 26.1.2, NeoForge 26.2, Forge 26.1.2 and Forge 26.2 pass (frames in docs/frames), so all ten builds now have world and screen frames.
- Headless self tests on those five pass: `SELFTEST DONE failures=0` with the 12 scripted-block checks (docs/testing/selftest-<module>.log). NeoForge 26.1.2 first failed because three server files in its run folder (banned-players, banned-ips, ops) were filled with zero bytes by the app crash; they were reset to `[]` (the run folder is not in git).
- The built Forge 1.20.1 jar `modjs-mc1.20.1-2026.11.32.jar` was loaded in a real Forge 47.4.28 install and in a real NeoForge 47.1.106 install (launch scripts and libraries from the BarelyQuesting session's scratchpad, game folders of our own, through launch-isolated.ps1). Both ran the overlay tour: overlays over the smelter and a plain block, the smelter's screen, and the smelter made 4 ingots (frames `worldoverlay-real-forge-1.20.1-*.png`, `worldoverlay-real-neo-1.20.1-*.png`, logs `worldoverlay-real-*-1.20.1.log`). No code changed, so the version stays 2026.11.32.

## Not run

- Dedicated server with a remote client: the block entity update and the menu use the normal vanilla packets, but a remote client was not connected.

## Fixes found by the client runs

- Text drawn by the font with a background box z-fought with its own background at a distance and half the letters vanished: the background is now a separate quad one layer behind.
- 26.x has no `textures/misc/white.png`; filled bars showed the missing texture tinted by their color. ModJS now ships `modjs:textures/misc/white.png`.
- On 1.20.1 text and bar fills were hidden behind their backgrounds (the billboard frame points the other way there); a half turn on 1.20.1 fixes it.
- Item icons were twice the intended size.
