# Testing 2026.11.36 (config API and user-file safety)

All ten builds carry the version bump (shared code; each build has a client tick call, the `/modjs reload config` command, a safer dimension folder delete and an atomic save of its dimensions file).

## Done and seen

- All ten builds compile.
- Unit tests (`neoforge-1.21.1 test`): `ConfigTest` (13 tests: format round trip with comments, parse leniency and broken text, validation of missing keys, wrong types, out-of-range values, unknown keys, coercion, choices, lists, nested groups, file creation, no rewrite on reload, `save()` with a `.bak` copy, sides and file names, script properties and nesting, schema errors, `onChange` for `set`, edited files and re-registered scripts), `UserFilesSafetyTest` (5 tests: a temp `modjs` tree with scripts, odd names, nested folders, JSON, binary files, a user `jsconfig.json`, `config/unify.json`, a config with comments and a `.bak`; the first-run, startup and reload routines run twice and every file is byte-identical, only `probe/modjs.d.ts` is added; examples only for folders that did not exist; the typings file rewritten only when it differs; `SafeFiles` never replaces what exists), plus all earlier tests.
- Headless self test, failures=0 on NeoForge 26.3, Forge 26.3 and NeoForge 1.21.1, including `config: registers a typed config, refuses an out-of-range value, writes a commented file and reloads it` and `user files: the startup routines leave every existing file in the modjs folder untouched` (runs the folder scaffolding twice against the real `run/modjs` and compares every file).

## Not run

- Self tests on the other seven builds (they compile and share the code).
- The client tick hook (`ConfigManager.tickClient`) and a client config in a real client: no client was launched (no screen was added). The server tick hook is covered by the self test only through `reload`, the one-second file polling by the unit test (`pollNow`).
- `/modjs reload config` in a running game (compiled on all ten builds, not run).
- Live reload on a dedicated server.
